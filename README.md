# 笑顔ウォッチ

PC のインカメラで作業中の**表情**と**まぶたの動き**を読み取り、笑顔が少ない状態や眠気のサインが続いたら画面上で声をかけるアプリケーションです。計測した値は CSV / JSON で書き出せます。単一の HTML ファイルで動きます。

![画面](https://github.com/user-attachments/assets/3eb16d1f-4458-42ec-864e-c5c3232a51d7)

## 使い方

`file://` で直接開くとカメラを使えません。ローカルサーバー経由で開いてください。

```bash
cd <smile-watch.html のあるフォルダ>
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000/smile-watch.html> を開き、「見守りを始める」からカメラを許可します。

開始から 30 秒はウォームアップです。その後、直近 1 分の**笑顔スコア**または**覚醒スコア**がしきい値を下回った状態が指定時間つづくと、励ましのメッセージが表示されます。一度表示すると 5 分間は再表示しません。両方の条件が重なったときは、眠気のほうを優先して声をかけます。

しきい値と判定時間は画面下で変更できます。既定値（笑顔 20 / 覚醒 45 / 90 秒）は目安なので、1 日使って体感で調整してください。スコアには個人差があります。

## 2 つのスコア

### 笑顔スコア

口角の形状（`mouthSmileLeft` / `mouthSmileRight`）から求めた 0–100 の値です。

### 覚醒スコア

まぶたの動きから求めた 0–100 の値です。次の 3 つを直近 1 分から計算し、重み付けして合成しています。

| 指標 | 見ているもの |
|---|---|
| PERCLOS | 一定時間に占める閉眼時間の割合。眠気指標として広く使われているもの |
| 開瞼ゆらぎ | 目の開き具合の標準偏差。眠くなると開き具合を一定に保てなくなる |
| 左右差 | 左右のまぶたの開き具合の差。眠くなると左右の動きが揃わなくなる |

後ろ 2 つは、NEC の「顔映像からの眠気（覚醒度）推定技術」が挙げるまぶたの 2 特徴（時間的ゆらぎ / 左右差）を借りた考え方です。どちらもゆっくりした変化なので、5 fps 程度の粗いサンプリングでも捉えられます。

- [生理情報認識：顔映像からの眠気（覚醒度）推定技術 — NEC](https://jpn.nec.com/rd/technologies/201801/index.html)
- [目元の情報から覚醒度を推定する技術の事業化 — NEDO NEP](https://nep.nedo.go.jp/selected/bfafd891-f180-48cd-8a47-daabd0587a5a)

**これらの技術そのものではなく、公開されている考え方を借りた簡易な近似実装です。**

指標の平常値は人によって、また環境によって大きく違います。そのためウォームアップ直後にその時点の値を**基準**として記録し、覚醒スコアは基準からの変化で判定します。「いまの状態を基準にする」ボタンでいつでも取り直せます。眠いときに基準を取ってしまうと眠気を検出しにくくなるので、目が覚めているときに取り直してください。

## データの書き出し

1 秒ごとのスコアをブラウザのメモリにためています。「記録」から CSV または JSON で保存できます。

- **CSV** — 1 行 1 秒。Excel で開いても文字化けしないよう UTF-8 BOM 付きで出力します。
- **JSON** — 上記に加えて、設定値・基準・イベント履歴（開始 / 停止 / 基準取得 / 励まし表示）を含みます。

| 列 | 内容 |
|---|---|
| セッション | 見守り開始ごとに増える通し番号 |
| 記録時刻 | ローカル時刻 |
| 経過秒 | そのセッション開始からの経過秒 |
| 顔検出 | その 1 秒に顔を検出できたか |
| 笑顔スコア / 笑顔スコア_1分平均 | 0–100 |
| 覚醒スコア | 0–100 |
| PERCLOS / 開瞼ゆらぎ / 左右差 | 覚醒スコアの内訳 |
| 平均開瞼度 | 0–1（1 = 全開） |

書き出されるのは**数値だけ**で、映像や画像は一切含まれません。

記録はメモリ上にしかありません。タブを閉じたり再読み込みすると消えます。最後の書き出し以降に記録が増えているときは、離脱前に確認します。上限は 8 時間分で、超えると古いものから捨てます。

## 動作環境

Chrome / Edge / Safari のデスクトップ版。

## プライバシー

カメラ映像の解析は端末内で完結します。映像の録画も外部送信も行いません。

ただし初回起動時に、解析モデル（約 3.7MB）と WebAssembly ランタイムを Google および jsDelivr の CDN から、Web フォントを Google Fonts から取得します。この通信で IP アドレスが各配信元に渡ります。完全にオフラインで動かしたい場合は、これらをリポジトリに同梱して参照先を差し替えてください。

## 制約

- 笑顔スコアは口角の形状のみを見ています。マスク着用・強い逆光・横顔では精度が落ちます。
- 覚醒スコアはまぶたの見た目だけから求めた簡易指標です。眼鏡の反射・伏し目がちな姿勢・照明の変化でも動きます。眠気そのものを測っているわけではなく、PVT や脳波と対応づけた検証も行っていません。重みやしきい値は経験的に置いた値です。
- 医療・メンタルヘルスの判定ではありません。休憩の目安として使ってください。
- 顔を 10 秒以上検出できない間は判定を止めます。
- タブが非アクティブの間は計測されません。
